# Privacy Policy — GitHub Pages structure

This archive is ready for GitHub Pages.

## Publish
1. Upload the contents of this archive to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/docs` folder.
5. Click **Save**.

The home page will be:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

Each product has its own clean URL, for example:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/capy-guardian-of-the-springs/`

Do not rename `index.html` files unless you also update links.
